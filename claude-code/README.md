# Sakuga Claude Code

`<sakuga-claude-code>` uses the exact pixel-art Claude Code mascot path from `CLAUDE-CODE-COLLECTION.md`, paired with Sakuga VFX springs, cel-ink outlines, and 6 interactive Japanese anime stories.

## Usage

```html
<script src="claude-code.js"></script>
<sakuga-claude-code story="ninja-dash"></sakuga-claude-code>
```

## Stories (`story` attribute)

- `ninja-dash` (忍者ダッシュ)
- `terminal-sprint` (端末疾走)
- `release-launch` (本番出荷)
- `coffee-compile` (珈琲コンパイル)
- `bug-hunt` (バグ討伐)
- `build-sleep` (ビルド昼寝)
