# Sakuga Claude Mascot

`<sakuga-claude>` adapts the Claude mascot from `vibe-svgs` into Sakuga VFX's two-tone cel-shaded Japanese anime aesthetic with 6 interactive coding stories.

## Usage

```html
<script src="claude-mascot.js"></script>
<sakuga-claude story="debug"></sakuga-claude>
```

## Stories (`story` attribute)

- `idle` (待機中): wrench pose, `カチッ` + `kira`
- `debug` (バグ退治): Japanese hachimaki headband, katana slash, bug shards, `シュッ`
- `ship` (出荷完了): rocket jump, `burst`, `shards`, `puff`, `ドン!`
- `hyper` (覚醒): overdrive aura, `lines`, `puff`, `ゴゴゴゴ`
- `coffee` (一服): Japanese teacup, rising `donut` steam rings, `ポン`
- `sleep` (昼寝): napping pose; clicking wakes Claude in shock (`ドン!` + `lines` + `wob`)
